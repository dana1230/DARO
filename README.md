# DARO

다로리 Figma 시안을 기준으로 만든 정적 퍼블리싱 프로토타입입니다. 화면의 제목, 버튼, 카드 내용은 이미지 안의 픽셀이 아니라 HTML 텍스트로 분리되어 있어 `script.js`의 데이터만 바꾸면 디자인을 유지한 채 문구를 수정할 수 있습니다.

## 열기

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## 구성

- `index.html`: 화면 구조
- `styles.css`: 반응형 레이아웃과 패널 스타일
- `script.js`: 화면 전환, 카드 데이터, 실제 텍스트 콘텐츠
- `assets/screens`: 이전 이미지 기반 프로토타입 참고 자산
- `assets/cards`: 이전 카드 이미지 참고 자산
